## 建表 SQL（schemaVersion = 1）

```sql
CREATE TABLE IF NOT EXISTS "characters" (
  "id" TEXT NOT NULL,
  "name" TEXT NOT NULL DEFAULT '',
  "display_name" TEXT NOT NULL DEFAULT '',
  "json" TEXT NOT NULL,
  "updated_at" DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY ("id")
);

CREATE TABLE IF NOT EXISTS "character_metas" (
  "key" TEXT NOT NULL,
  "value" TEXT NOT NULL,
  PRIMARY KEY ("key")
);
-- key: deleted_default_ids | visibility_groups

CREATE TABLE IF NOT EXISTS "conversations" (
  "id" TEXT NOT NULL,
  "character_id" TEXT NOT NULL DEFAULT '',
  "character_name" TEXT NOT NULL DEFAULT '',
  "json" TEXT NOT NULL,
  "last_message" TEXT NOT NULL DEFAULT '',
  "last_message_time" DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  "unread_count" INTEGER NOT NULL DEFAULT 0,
  "pinned" INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY ("id")
);

CREATE TABLE IF NOT EXISTS "messages" (
  "id" TEXT NOT NULL,
  "conversation_id" TEXT NOT NULL,
  "json" TEXT NOT NULL,
  "is_from_user" INTEGER NOT NULL DEFAULT 0,
  "type" TEXT NOT NULL DEFAULT 'text',
  "created_at" DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY ("id")
);

CREATE TABLE IF NOT EXISTS "chat_metas" (
  "key" TEXT NOT NULL,
  "value" TEXT NOT NULL,
  PRIMARY KEY ("key")
);
-- key: context_tokens | system_tokens | roleplay_choices

CREATE TABLE IF NOT EXISTS "migration_flags" (
  "name" TEXT NOT NULL,
  "completed_at" DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY ("name")
);

CREATE INDEX IF NOT EXISTS idx_messages_conv_time
  ON messages (conversation_id, created_at);
CREATE INDEX IF NOT EXISTS idx_conversations_updated
  ON conversations (last_message_time);
```

## 迁移策略

1. `StorageMigrationService.init()`（`main` 启动时）
2. 检查 `migration_flags.name = prefs_to_sqlite_v1`
3. 未完成则：
   - 备份上述 key 原始值 → `documents/db_migration_backup/prefs_migration_*.json`
   - 解析 JSON 写入 SQLite（角色 / 会话 / 消息 / meta）
   - 写入迁移标记
4. **不删除** SharedPreferences（保留 fallback）
5. Provider 本阶段未改读写（仍走 SharedPreferences）；下一切片可切换双读/双写

## 升级不丢数据保证（2026-09-27 加固）

| 场景 | 行为 |
|------|------|
| 旧版本只有 prefs 升上来 | 首次启动自动备份 + 导入 |
| 迁移中途失败 | **不打标**，prefs 原样保留，下次启动重跑 |
| 打标后库被清空/损坏，prefs 仍有 | `needsRepair()` 自动重导 |
| SQLite 读失败/为空 | `LocalDataStore` 回退 SharedPreferences |
| 双写时 SQLite 失败 | prefs 已写入，可由修复导入补齐 |
| 新安装 | prefs 为空，直接打标 |

校验规则：源有 N 条记录则库内行数必须 ≥ N，否则视为迁移失败。
