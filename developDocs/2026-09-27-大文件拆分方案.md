## 二、优先：`chat_screen.dart`（109 KB）拆分方案

### 现状职责（同一 State 内）

| 行号区间 | 职责 | 方法摘要 |
|---------|------|---------|
| 43–64 | 类型/State 字段 | `_MemorySaveMode`、`ChatScreen` |
| 119–275 | 生命周期与滚动 | `initState`、`dispose`、scroll |
| 276–438 | 导入导出 | `_exportChat`、`_importChat` |
| 440–748 | 气泡菜单 / 思考展示 | `_showBubbleMenu`、`_showReasoningContent` |
| 750–1368 | 消息操作 | 分支、编辑、撤回、重回、剧情建议 |
| 1370–1910 | 多选转发 / 记忆点 | `_enterSelectMode`、`_saveSelectedAsMemory` |
| 1912–1984 | 功能检测弹窗 | `_runFeatureDetect` |
| 1986–2343 | AI 回复 / 发送 / 朗读 | `_triggerProactiveMessages`、`_speakMessage` |
| 2345+ | `build` 消息列表 UI | 树很大 |

### 建议拆分（7 个文件）

```
lib/screens/chat/
├── chat_screen.dart              # 入口：State 字段、生命周期、build、发送 (~25KB)
├── chat_message_menu.dart        # 纯 UI：长按菜单面板 / 菜单项 (~12KB)
├── chat_message_actions.dart     # 消息操作：编辑/撤回/分支/重回/思考 (~20KB)
├── chat_select_forward.dart      # 多选 + 转发 + 存记忆点 (~18KB)
├── chat_proactive_reply.dart     # 触发 AI 回复/朗读/功能检测 (~22KB)
├── chat_plot_suggestion.dart     # 剧情建议流程 (~12KB)
└── chat_import_export.dart       # 聊天记录导入导出 (~10KB)
```

### import 关系（拆后）

```
chat_screen.dart
  ├─ chat_message_menu.dart      (widgets only)
  ├─ chat_message_actions.dart   (uses ChatProvider / CharacterProvider)
  ├─ chat_select_forward.dart
  ├─ chat_proactive_reply.dart
  ├─ chat_plot_suggestion.dart
  └─ chat_import_export.dart

各子文件向上依赖：
  models/message.dart
  providers/*（chat、character、api、settings、memory…）
  widgets/chat_bubble.dart、message_input.dart
  services/llm_service.dart、prompt_builder.dart
```

### 实现约束

1. **不改对外 API**：`ChatScreen(conversationId, characterName, characterAvatar, initialMessageId)` 不变
2. **状态留在 `_ChatScreenState`**：菜单/进度等 ephemeral state 不下沉
3. **纯函数/纯 Widget** 尽量进 `chat_message_menu.dart`
4. **带 Context 的操作** 用 `ChatMessageActions` 等类接收 `BuildContext` + provider 引用，避免 extension 跨文件摸私有 State
5. 每拆一个文件：`flutter analyze` + 写 `developDocs/` 拆分记录
6. 公共枚举 `_MemorySaveMode` 提升为 `MemorySaveMode`（可放 `chat_select_forward.dart` 并 export）

| chat_message_actions.dart | 单条消息编辑/撤回/分支/思考查看 |
