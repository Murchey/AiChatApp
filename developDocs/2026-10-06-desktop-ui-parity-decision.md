# AiChatApp 桌面版 UI 与手机版功能一致性决策

日期：2026-10-06

## 目标

让 Windows 桌面版具备手机版已有的主要聊天能力，并把桌面交互调整为 Apple / iMessage / ChatGPT 风格。业务数据、Provider 和手机端页面继续作为唯一业务来源，避免桌面端复制一套会逐渐分叉的回复逻辑。

## 已采用的方案

1. **统一视觉 token**
   - 桌面色板迁移到 Apple system background、surface、Apple Blue 和 iMessage 蓝灰气泡。
   - 浅色背景使用 `#F5F5F7`，深色背景使用 `#0B0B0F`；边框、选中态、输入区和文字均按明暗模式成对定义。
   - 左侧功能栏、列表面板、主聊天区和详情面板使用独立 surface 层，圆角和留白优先于旧微信绿色大块填充。

2. **私聊与群聊统一会话入口**
   - 桌面消息列表将 `ChatProvider.conversations` 与 `GroupChatProvider.groups` 合并排序，置顶和最近消息时间规则一致。
   - 群聊支持桌面右键置顶、标记已读、删除，并在联系人页同时显示群聊和角色。
   - 群聊头像没有自定义图片时使用成员图标回退，避免空白头像。

3. **群聊业务复用手机版实现**
   - `GroupChatScreen` 增加 `embedded` 模式，只隐藏手机导航栏，消息流、@成员、图片/文件、导入导出、剧情建议、记忆点、群回复调度和错误处理仍由同一页面代码负责。
   - 新增 `DesktopGroupChatView` 提供桌面标题栏、群聊设置和群聊详情入口；不会复制群聊 Prompt 或回复调度。

4. **私聊桌面操作补齐**
   - 消息时间分组、思考耗时、文件打开、错误提示、聊天记录导入/导出、图片能力检测和剧情建议接入手机版已有服务。
   - 右键消息支持复制、选择文本、引用、保存记忆点、查看思考过程、重新生成、撤回并编辑和删除。
   - 角色文本消息保留 TTS 朗读入口；聊天标题栏提供全局聊天记录搜索，支持 `Ctrl/Cmd+Shift+F`。
   - 输入栏继续使用手机版 `MessageInput`，因此贴纸、图片、文件、语C候选、对号触发回复和 Enter 发送保持一致。

5. **桌面响应式与键盘操作**
   - 列表宽度和左侧功能栏在窗口宽度较小时收窄，标准窗口保留三栏结构。
   - `Ctrl/Cmd+K` 与 `Ctrl/Cmd+F` 聚焦搜索，`Ctrl/Cmd+,` 打开设置，`Esc` 清除搜索或关闭聊天侧栏。
   - 桌面设置使用新的标题和卡片容器包裹手机版完整设置列表；手机新增设置项会自动出现在桌面。

## 边界与后续观察

- 朋友圈和局域网同步仍直接复用手机页面，先保证入口和业务能力一致；后续可根据窗口截图再做宽屏专用双栏布局。
- 群聊详情和群聊设置目前通过桌面标题栏打开二级页面，数据与手机端完全共享，避免在桌面侧维护第二个编辑表单。
- 没有执行任何 Git 命令、提交、推送或远程仓库操作。

## 验证

- `flutter analyze lib`：通过（仅保留仓库原有 lint info）。
- `flutter test`：全部通过。
- `flutter build windows`：构建成功，产物为 `build/windows/x64/runner/Release/ai_chat.exe`。
