# AiChat 应用主题制作指南

主题是 ZIP 文件，根目录必须有 `content.json`。导入只安装，不自动启用；在【我 → 应用主题 → 已安装】预览并启用。可随时禁用、导出、删除。主题的图片和默认颜色在深浅模式下共用。

## 示例和文件结构

可直接导入 [soft-cloud-theme.zip](../docs/soft-cloud-theme.zip)。源文件在 [theme-example](../docs/theme-example/)，完整清单见 [content.json](../docs/theme-example/content.json)。示例字体 DejaVu Sans 的许可随包保留在 `fonts/LICENSE_DEJAVU`；它演示我方字体加载，未覆盖的中文由系统字体补齐。发布自己的字体时应保留相应再分发许可。

心月狐的完整制作过程见 [心月狐主题制作实战](心月狐主题制作实战.md)。个人主题的原始素材和生成包保留本地并由 `.gitignore` 排除；操作指南、制作脚本及通用测试示例仍随源码保留。

```text
content.json
images/
  chat.png / chat-selected.png
  contacts.png / contacts-selected.png
  discover.png / discover-selected.png
  profile.png / profile-selected.png
  home-header.png / contacts-header.png
  self-bubble.png / preview.png
fonts/
  self.ttf
  LICENSE_DEJAVU
```

打包时选择这些内容直接压缩，不要在 ZIP 外再套一层主题文件夹。所有路径相对于 `content.json`，区分大小写；只使用 `/`，不允许绝对路径、`..`、反斜杠或网络 URL。

## 清单字段

| 字段 | 类型与用途 |
| --- | --- |
| `id` | 必填；1–64 位字母、数字、下划线、短横线，首位必须字母或数字；作为本地主题标识。重复 ID 导入时需确认替换 |
| `name` | 必填；非空显示名称 |
| `author`、`description` | 可选；作者和简介 |
| `preview` | 可选；预览图片相对路径，不参与主题效果 |
| `navigation` | 可选；四个槽位 `chat` / `contacts` / `discover` / `profile`。每个槽位都必须有 `normal`、`selected` 图片路径和 `width`、`height` 实际像素尺寸 |
| `headers` | 可选；`home` 和 `contacts` 各自包含 `file`、`width`、`height` |
| `selfBubble` | 可选；`file`、`width`、`height`、`stretchInsets` 和 `textColor` |
| `selfFont` | 可选；`file` 为 TTF 路径，`name` 为字体说明名称；应用中按主题名称展示 |

除 ID 和名称外，至少要有一项可应用资源；没有提供的槽位使用应用原样式。不需要 `schemaVersion` 或 `version` 字段。未知扩展元数据会随导出保留。

### 导航图片

只支持静态 PNG/JPG/WebP，推荐透明 PNG、96×96。每个槽位选中态、未选中态分别制作；两张图片尺寸必须与清单一致。槽位可增加 `size` 指定显示边长（16–36 个逻辑像素），省略时使用原导航尺寸；心月狐使用 `36`。App 对主题导航图片额外放大 10%（36 显示为 39.6），已安装主题也直接生效，无需重新导入。导航文字变大时，App 会按剩余高度等比缩小图标，避免底部溢出。`width/height` 仍是文件实际像素。应用不给图片额外染色，原有标签、红点、点击区域不变。底部悬浮导航和底栏模式均支持。

### 顶部背景

`headers.home` 对应会话首页，`headers.contacts` 对应通讯录。启用对应 Header 背景后，顶部栏内容高度从 44 增加到 60 个逻辑像素，另加状态栏安全区域；禁用后恢复原高度。图片铺满整个顶部栏背景；标题、搜索和加号仍保留，并在加高后的区域居中。可使用 750×150、250×75 等尺寸，但必须如实填写实际宽高。应用等比缩放铺满（`BoxFit.cover`），水平居中、偏上取景（垂直对齐 -0.4，兼顾眼睛和上方装饰），超出区域裁切，不把人物压扁；重要内容尽量放在上方安全区域。不同设备的栏高和宽高比不同，可见范围会变化。应用会叠加轻量明暗遮罩提高按钮可读性。

### 我方气泡

使用默认样式的布局、内边距和底版，不改变角色气泡、图片、附件、表情包。底图参考 [self-bubble.png](../docs/theme-example/images/self-bubble.png)，九宫格示意参考 [bubble-stretch-guide.png](../docs/theme-example/bubble-stretch-guide.png)。

需要在气泡左侧边缘显示角色装饰时，可增加可选的 `selfBubble.leading`，例如：

```json
"leading": {
  "file": "images/bubble-leading.png",
  "width": 320,
  "height": 320,
  "size": 40,
  "gap": 8
}
```

`width/height` 是实际像素；`size` 是显示方框边长（逻辑像素，默认 40，范围 16–96），图片等比缩放，不拉伸；`gap` 是图片与正文间距（默认 8，范围 0–24）。图片叠在气泡左边缘，40% 宽度探出左侧、顶部探出 8 个逻辑像素；正文和外层布局为装饰预留空间，避免遮字或裁切。无此字段保持原布局。装饰图与气泡底图分别存放，避免人物随长消息被九宫格拉伸。导入会校验装饰图，运行时丢失则跳过显示。

选中与未选中图片可以引用同一个文件，无需复制资源或自行绘制选中标记；导航的既有选中反馈继续生效。完整实践参见 [心月狐主题制作实战](心月狐主题制作实战.md)。使用 `leading` 的主题需要包含此功能的新版 App。

`stretchInsets` 的 `left/top/right/bottom` 是源图像素，标明四边固定区域；中心拉伸，边角保形。值不得为负，左右之和必须小于宽度，上下之和必须小于高度。应用会把像素边距缩放到气泡布局适用尺寸，短消息也不会把固定边撑坏。示例为 240×120，四边各 24 像素。不要把重要装饰伸进文字内边距区域。

`textColor` 是 `#RRGGBB` 格式的默认我方文字色，例如 `#202124`。用户可在【设置 → 显示 → 气泡与文字颜色】关闭主题气泡，或分别修改深浅模式文字色；也可从气泡样式页进入。主题启用后，气泡和文字颜色统一在此页面调整：我方图片底色由主题素材决定，不提供无效的改色入口；我方文字颜色可分深浅模式设置；对方颜色沿用原样式，固定配色样式会明确说明。关闭主题气泡后恢复原气泡颜色选项。禁用主题后恢复原设置。

### 字体与资源限制

`selfFont.file` 仅支持有效 TTF，路径如 `fonts/self.ttf`。启用时自动用于我方聊天正文，字体设置中可切换主题字体、系统默认或已有导入字体。不会改界面字体、角色字体，也不会覆盖同名本地字体。

ZIP 最大 50 MiB，解压后总计最多 200 MiB、4096 项。图片最大单边 8192 像素、总像素不超过 16,777,216；禁止动态图。尺寸不符、资源缺失、字体损坏、重复路径或不安全路径会拒绝整包，原主题不变。

## 发布到仓库或对象存储

- GitHub/Gitee：创建标签精确为 `ThemeStore` 的 Release，将 ZIP 上传为 Release 附件。仓库源码中的 ZIP 不会自动成为 Release 附件。
- COS/OSS：桶根目录配置为 `https://bucket.example.com/` 时，将主题放在 `Theme/柔云.zip`；来源配置为 `https://bucket.example.com/workshop/` 时，放在 `workshop/Theme/柔云.zip`。`Theme` 大小写必须一致，ZIP 直接放该目录下。对象存储目录名为 `Theme/`，与 GitHub/Gitee 的 `ThemeStore` Release 标签分别配置。
- 对象存储需要列举配置路径及读取 ZIP 的权限；私有桶填写 SecretID/SecretKey。主题浏览不需要写权限，不把密钥放进 ZIP。
- 【应用主题 → 右上角齿轮】独立配置来源，也可从创意工坊复制；之后两处配置独立维护。在线列表仅展示上述主题来源中的 ZIP，角色包和更新通知不受影响。
- 更新主题时沿用 ID。用户下载后确认替换；应用先校验、再替换，失败保留旧主题。多人发布同一个附件时应先完成上传再发布，避免用户读到半成品。

## 本地管理、备份和回退

【应用主题】顶部刷新按钮按当前栏目工作：【已安装】重新读取本地主题，【在线主题】重新拉取全部已配置来源，并绕过对象存储列表缓存。首次切到在线栏目自动加载，返回来源配置后更新列表；搜索仅过滤已加载的主题名称，支持拼音，不额外联网。与创意工坊一致，可先勾选多个 ZIP，再点击底部【下载导入】查看下载进度；导入后仍需手动启用。部分来源刷新失败时保留该来源上次列表，显示失败信息和重试入口。

同时只能启用一个主题。第一次启用使用包内默认值，之后恢复该主题自己的调整；禁用恢复原设置。删除使用中的主题需确认。安装文件、来源、启用状态和调整纳入数据备份，存储管理单独统计，不会被缓存清理删除。导出 ZIP 不包含仓库配置或密钥。

自选桌面图标与应用主题互相独立：Android 预置图标切换原应用图标；自选图片创建额外桌面快捷方式。备份恢复后需再次确认添加快捷方式。
