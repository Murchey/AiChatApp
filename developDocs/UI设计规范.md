# AiChat UI 设计规范

版本：v1.0  
适用范围：AiChat 手机端（Flutter / Cupertino）与电脑端（微信风格桌面 UI）  
目标：统一字体、间距、颜色与组件用法，新旧页面可对照落地。

---

## 1. 设计原则

1. **信息优先**：内容层级靠字重/字号/颜色区分，不靠大色块堆砌。
2. **熟悉感**：交互与视觉贴近微信/系统设置，降低学习成本。
3. **双端一致、表现分端**：语义色与间距全端统一；手机用系统圆角列表，桌面用微信三栏。
4. **可访问性**：正文对比度 ≥ 4.5:1；不单靠颜色传达状态（配合文案/图标）。

## 3. 字体与排版

### 3.1 字体

| 端 | 字体 |
|----|------|
| iOS / Android | 系统默认（SF / 系统中文字体），**不指定 fontFamily** |
| Windows 桌面 | `Segoe UI`，回退 `Microsoft YaHei UI` → `Microsoft YaHei` → `PingFang SC` → `sans-serif` |

### 3.2 字号阶梯（pt / logical px）

| 角色 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| 大标题 | 28–30 | 700 | 1.2 | 数据大数字、空态主标 |
| 页面标题 | 17 | 600 | 1.3 | 导航栏标题、桌面顶栏 |
| 条目主文 | 15–16 | 500/400 | 1.4 | 列表标题、聊天正文 |
| 正文 | 14–15 | 400 | 1.5–1.65 | 说明段落、气泡 |
| 次要 | 12–13 | 400 | 1.4–1.5 | 副标题、设置说明 |
| 极小 | 10–11 | 400/500 | 1.2 | 角标、时间、菜单格文字 |

**聊天正文默认 15–16，高度 1.45–1.65。** 表格/统计数字可用 `FontFeature.tabularFigures()`。

### 3.3 颜色层级

- 标题/正文：`textPrimary`
- 说明/占位：`textSecondary`
- 时间/弱提示：`textSecondary` 或 60% 透明
- 强调/可点：`accent`
- 错误/删除：`danger`

## 4. 间距与布局

### 4.1 间距标（8 网格，允许 4 半格）

| Token | 值 | 用途 |
|-------|-----|------|
| xs | 4 | 图标与文字、角标 |
| sm | 8 | 列表内小间隙、按钮组 |
| md | 12 | 列表项内边距、卡片留白 |
| lg | 16 | 页面左右边距、区块间距 |
| xl | 20–24 | 大区块、弹窗内边距 |

### 4.2 页面边距

- 手机列表/表单：左右 **16**
- 聊天消息：左右 **12**（头像 40 + 间距 8）
- 桌面主区：**20–24**；列表面板左右 **8–12**
- 弹窗内容：上下 **12–16**，左右随系统 AlertDialog

### 4.3 分组与设置页

- 设置页采用 Obsidian 式分组：页面背景与中性圆角面板分层，面板圆角 **22**，分组之间保留约 **24** 留白。
- 分组标题：`textSecondary`，约 **15** 号、`w600`；标题位于面板外侧并保留顶部留白。
- 设置行最小高度约 **62**，图标占位宽度约 **38**，标题 **16**、说明 **12**。
- 分割线：高 **0.5**，低透明度，从图标区域右侧开始；暗色模式避免连续亮线。
- 普通前导图标与箭头使用中性 `textSecondary`；开关、滑杆、选中、主操作、成功和危险状态保留语义色。
- 设置导航栏使用居中标题、低对比度背景和圆形返回按钮，继续保留系统返回手势。

### 4.4 移动端浮层壳

- 首页底部导航提供两种可切换样式，设置 → UI 样式中即时生效：
  - **悬浮胶囊（默认）**：高度 **64**、左右 **16**、底部 **8 + 安全区**，半透明悬浮在页面内容上方。
  - **底部面板**：保留重构前嵌入页面底部的一行 `CupertinoTabBar`，与页面底色和弱分割线衔接。
- 悬浮胶囊与聊天输入区可使用轻毛玻璃；首页导航模糊约 **22**，普通列表和设置分组不铺满主题色。
- 首页导航使用页面内容透出的半透明中性表面（浅色约 **70%**、深色约 **58%**）；选中胶囊使用中性抬升表面、细主题色描边和轻阴影，主题色只放在图标与文字。
- 导航选中态使用共享胶囊滑动指示器和短时淡入图标；未选中图标保持次要文字色。
- 首页会话行高约 **76**，列表头像 **44**；普通图标、静态信息和头像占位使用中性色。
- 个人页资料卡和分组面板采用 **22** 圆角的中性设置表面；通讯录列表分割线使用低对比度颜色，暗色模式避免连续亮线。

## 6. 组件规范

### 6.1 导航栏（手机）

- 高度：系统 `CupertinoNavigationBar`（约 44 + 安全区）
- 标题：17 / w600，居中（终末地 UI 可左对齐）
- 左右操作：`accent` 或 `textSecondary`，16
- **禁止**自造顶栏，除非桌面端
- 首页底部四入口使用悬浮半透明胶囊；选中项使用中性抬升胶囊，`accent` 仅用于图标、标签和细描边。

### 6.2 列表条目 ListTile

| 属性 | 规范 |
|------|------|
| 高 | 56–76（首页会话行约 76） |
| 头像/图标 | 40–48（聊天）/ 24–28（设置） |
| 主文 | 15–16 |
| 副文 | 12，`textSecondary` |
| 右侧 | 值文字 14 + 箭头 14–16 |
| 点击 | 整行可点，`opacity` 或背景轻反馈 |

资料卡条目复用 `ChatInfoTile`；备份页操作项复用 `BackupActionTile`。

### 6.3 按钮

| 类型 | 样式 |
|------|------|
| 主按钮 | `CupertinoButton.filled` 或 `accent` 底 + 对比字色，高 40–44 |
| 次按钮 | 灰底 6–12% 透明 + 主字色 |
| 危险按钮 | `danger` 字/底 |
| 文字按钮 | 无底，`accent` / `danger` |
| 迷你按钮（备份列表） | 高 32，水平 12，圆角 8，底为色 12% 透明 |

同一区域最多 **1 个主按钮**。

### 6.4 输入框

- 聊天输入区外层使用半透明浮层胶囊，圆角 24；内部输入字段使用 `fieldBg`，圆角 18，内边距 10–14
- 字号 15–16
- 多行：`maxLines: null` 或 4–8，`textAlignVertical: top`
- 占位符：`textSecondary`
- 密码：`obscureText: true`

### 6.5 对话框 / 弹层

| 类型 | 使用场景 |
|------|----------|
| `CupertinoAlertDialog` | 确认、警告、短提示、单字段（尽量少） |
| 二级页 `CupertinoPageRoute` | 复杂表单（提示词、定时备份、对象储存） |
| `CupertinoActionSheet` | 少选项（需要独立上下文的操作） |
| `showCupertinoModalPopup` | 取色器、模型选择等面板 |

**规范：** 超过 2 个输入项或需滚动 → **用二级页，不用弹窗**。

设置页中的离散选择器（主题模式、头像框、颜色、气泡样式、字体、导航样式等）使用锚定在条目下方的轻量浮动面板。面板继承设置页中性表面、圆角和低对比度描边，带短时淡入缩放；当屏幕底部空间不足时在条目上方展开并限制在可视区域内。选择后即时关闭并保留原有持久化逻辑。复杂编辑器、删除确认、API 模型编辑和系统文件选择继续使用二级页或系统弹层。

### 6.6 聊天气泡

- 气泡内边距：**12–14** 水平，**10** 垂直
- 字号 15–16，行高 1.45+
- 头像 40（手机）/ 40（桌面），间距 8–10
- 时间标签：居中灰底胶囊，字号 11
- 思考时长：气泡下左侧小标签，11 号
- 自己消息右对齐，对方左对齐

### 6.7 头像

| 形态 | 尺寸 |
|------|------|
| 聊天消息 | 40 |
| 会话列表 | 44–48 |
| 资料卡 | 64–72 |
| 侧栏 | 42 |

形状跟随设置「方形 / 圆形」；默认方形圆角 `size × 0.16`。

### 6.8 标签 / 角标

- 未读：红底白字，最小宽 18，字号 11，圆角 10
- 「加密」等状态：`accent` 12% 底 + accent 字，字号 10–12
- 分段控制：`CupertinoSegmentedControl`，上下 8、左右 18

### 6.9 进度

- 条：高 8，圆角 4，槽 `separator`，填充 `accent`
- 旁注：阶段文案 12 `textSecondary` + 百分比 12 `accent`
- 不确定等待：`CupertinoActivityIndicator`（半径 10）

### 6.10 空态

- 图标 48–72，`textSecondary`
- 主文 13–16，副文 12–13，居中，行高 1.5

## 7. 电脑端布局（微信风）

```
侧栏 68px │ 列表 300px │ 主区（伸展）
```

- 侧栏：深色竖条，图标 24，选中底 `railItemBg`，图标高亮 `#95EC69`
- 列表：搜索 + 会话/联系人；行高 64–68
- 主区：顶栏 64 + 内容 + 底部输入
- **交互：** 右键菜单、Enter 发送、Ctrl+F 搜索、Esc 关面板；不用长按/返回栈弹层做设置

---

## 8. 可访问性与状态

- 点击目标 ≥ 44×44（手机）
- 禁用态：`textSecondary`，不可点
- 错误：`danger` 字色 + 文案，不只靠颜色
- 加载：进度条或指示器，文案说明阶段
- 确认删除：AlertDialog + `danger` 确认钮

---

## 9. 代码约定

```dart
// ✅ 取色
context.listBgColor
context.textSecondaryColor
DesktopPalette.of(context).bubbleSelf

// ❌ 禁止（业务 UI）
Colors.white
Color(0xFFEDEDED) // 除非定义在 theme.dart / desktop_theme.dart
```

- 间距：优先 `EdgeInsets.symmetric(horizontal: 16)` 等标值，避免 `13`、`17` 随手写
- 字号：用本文字阶，不新造
- 新组件：优先复用 `ChatInfoTile`、`BackupActionTile`、`ChatBubbleMenuPanel`、`CharacterAvatar`、`WorkingProgressBar`
