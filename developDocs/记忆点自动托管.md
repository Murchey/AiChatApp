# 记忆点自动托管（AI 剧情记录）

## 功能概述

在「聊天设置」中开启「记忆点自动托管」后，1对1 私聊每累计 **10 条消息**，
AI 会静默做一次**剧情记录**：把最近对话里的剧情推进要点整理进记忆点的
「AI 托管」分区。托管记录随现有记忆点通道（`MemoryPointProvider.pointsFor`）
自动回传到系统提示词，让角色长期记住剧情。

记忆点管理页分为两个分区：

| 分区 | 内容来源 | AI 权限 | 用户权限 |
| --- | --- | --- | --- |
| AI 托管 · 剧情记录 | 自动托管写入（sourceType == 'auto'） | 可增 / 改 / 删 | 查看、搜索、批量删除、单条编辑/删除 |
| 我的记忆 | 手动添加、长按保存、故事线社区安装 | 无 | 同上 |

两分区均支持顶部搜索框全文过滤；导航栏「选择」进入多选模式，可全选并批量删除。

## 触发规则

- 开关：聊天设置 →「记忆点自动托管」→「自动记录剧情记忆」（默认关闭，
  prefs key `chat_auto_memory_enabled`）。
- 计数：按会话累计消息条数（用户消息、角色回复、剧情行动等全部计数）；
  游标 = 上次成功录制时的消息条数（会话 meta `auto_memory_cursors_v1`）。
- 触发时点：**AI 回复流程完成后**（`ChatProvider.autoMemoryRecorder` 钩子，
  移动端 / 桌面端统一收口）。只发消息未触发回复时，凑满 10 条后在下一次
  回复完成时补记一次（一次覆盖期间全部新增）。
- 录制窗口：最近 30 条消息（跳过空内容、压缩摘要、表情/图片/文件；
  剧情行动标注「【剧情行动】」）。
- 模型：使用「聊天设置」中选定的聊天模型；未选模型时静默跳过。

## AI 操作协议

录制请求要求模型以「剧情记录员」身份输出 JSON 操作数组
（见 `buildPlotMemoryInstruction`）：

```json
[
  {"op":"add","content":"与林澈约定明晚在旧码头交接账本"},
  {"op":"update","id":"<现有id>","content":"改写后的记录"},
  {"op":"delete","id":"<现有id>"}
]
```

约束与兜底：

- 每条记录为精炼剧情要点（≤ 60 字），只记事实/约定/关系变化/关键物品线索。
- 解析（`AutoMemoryOp.parseList`）容错：剥离代码围栏、容忍前后杂文、
  忽略非法项；单次最多 12 个操作，内容截断至 200 字。
- **越权保护**：update/delete 仅作用于 `sourceType == 'auto'` 条目，
  指向用户记忆 / 故事线记忆的请求在 `MemoryPointProvider.applyAutoOperations`
  中被忽略；add 与现有内容重复时跳过。
- 请求成功即推进游标（即使解析结果为空，避免空记录反复触发）；
  请求失败不推进游标，下一次回复完成后自然重试，不打扰用户。

## 数据与代码位置

- `lib/models/auto_memory_op.dart`：操作模型与容错解析。
- `lib/models/memory_point.dart`：`sourceTypeAuto = 'auto'`、`isAutoManaged`。
- `lib/providers/memory_point_provider.dart`：`autoPointsFor` /
  `applyAutoOperations` / `removePoints`（批量删除）。
- `lib/providers/chat_settings_provider.dart`：`autoMemoryEnabled`。
- `lib/services/llm_service_generate.dart`：`generatePlotMemoryRecords` /
  `buildPlotMemoryInstruction`。
- `lib/services/auto_memory_service.dart`：阈值判断、录制编排、游标持久化。
- `lib/providers/chat_provider.dart`：`autoMemoryRecorder` 回调（回复完成时触发）。
- `lib/app.dart`：`_setupAutoMemoryRecorder` 注册回调。
- `lib/screens/memory_point_manage_screen.dart`：双分区 / 搜索 / 批量删除。

## 边界说明

- 仅支持 1对1 私聊；群聊暂不托管。
- 记忆点管理页同时被群成员记忆页复用：该场景下「AI 托管」分区为空占位。
- 角色包导出 / 备份恢复包含托管条目（沿用全量记忆点导出的现状）。
- 清空聊天导致游标大于消息数时，按当前消息数重新起算。
