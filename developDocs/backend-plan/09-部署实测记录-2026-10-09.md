# 部署实测记录（2026-10-09）

## 部署目标

目标服务器：Ubuntu 云服务器（`ubuntu@118.89.77.164:22`）。部署内容为当前工作区 `server_project/build/libs/aichat-backend.jar`，使用 systemd 托管，SQLite 数据目录位于 `/opt/aichat/data`。

## 已执行步骤

1. 通过 SSH Agent 连接服务器，未读取或传输 PEM 私钥内容。
2. 安装 `openjdk-21-jre-headless`，并确认 Java 21.0.12.1。
3. 创建 `aichat` 系统用户、`/opt/aichat/data`、`/opt/aichat/config` 和 release 目录。
4. 构建并上传当前 JAR，安装 `deploy/aichat.service`。
5. 生成服务端 token pepper 和 bootstrap 管理令牌；配置文件为 `/etc/aichat/aichat.env`，管理令牌文件为 `/opt/aichat/admin-bootstrap-token.txt`，两者权限为 600。
6. 启用并启动 `aichat.service`。
7. 确认 Flyway V1–V8 全部迁移成功。

## Android 模拟机验收

由于云安全组暂未放行公网 8080，本次通过本地 SSH 隧道 `127.0.0.1:18080 -> 服务器127.0.0.1:8080`，并使用 `adb reverse` 提供给 Pixel 6 模拟机。

临时开启同步试点后执行：

```text
flutter test test/integration/backend_sync_live_test.dart -d emulator-5554 --no-pub
```

结果：`All tests passed!`，覆盖管理员邀请码、设备绑定、同步域开启、AES-GCM 密文上传、下载、客户端解密和设备撤销。测试结束后已将 `AICHAT_FEATURE_SYNC` 恢复为 `false` 并重启服务，健康检查再次通过。

APK 通过 `flutter build apk --debug --no-pub` 构建，并用 `adb install -r` 安装到 Pixel 6。应用进程启动正常，没有 `FATAL EXCEPTION` 或进程崩溃标记；模拟器出现的 Impeller EGL 提示属于图形后端警告。

## 公网接入待办

服务器本机 UFW 处于 inactive，Java 正监听 `0.0.0.0:8080`；从公网访问 8080 未通过，需在云厂商安全组中增加 TCP 8080 入站规则，建议只允许自己的 IP 或测试网段。

正式部署应使用域名、Caddy/Nginx HTTPS 反向代理，并关闭公网直连 8080。放行或配置代理后，App 在“发现 → 故事线社区 → 设置”中填写服务地址、端口和设备邀请码即可连接。
