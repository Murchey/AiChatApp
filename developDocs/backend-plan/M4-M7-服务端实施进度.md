# M4–M7 服务端实施进度

更新日期：2026-10-09。M4–M7 的服务端核心接口、迁移和自动化回归已完成；下列边界是客户端或部署环境验收项，不将其误报为服务端缺陷。Git 仅执行 status/diff/log 等只读命令。

## M4 管理员故事发布：已实现服务端主流程，验收进行中

- 新增 V3 `story_draft` 与发布幂等响应表，V4 邀请码角色字段；V1/V2 不修改。
- 草稿创建、读取、修订更新、字段校验、提交审核、不可变发布和归档接口。
- 更新草稿与发布内容分开存储，编辑不会使已发布故事下线；第二版本发布保留旧版本。
- 每次修改检查 revision，发布再检查 baseVersion；重复幂等键只返回原结果，键绑定不同请求返回冲突。
- 管理员草稿与审计列表均使用 SQL cursor + LIMIT 分页。
- 管理员可生成 ADMIN 邀请码，兑换角色由服务器授予；普通客户端不能自行选择角色。
- 直接导入发布接口继续兼容已有管理脚本，现已遵守 admin-publish 功能开关。
- `StoryDraftControllerTest` 覆盖发布闭环、第二版本、冲突、重复发布、归档、坏草稿、权限与管理员邀请码。

迁移、草稿revision并发、角色重新绑定安全和部署说明已有回归与文档覆盖；管理员编辑器/API 客户端仍属于未接入的 App 层边界，服务端接口不宣称编辑器已完成。

## M5 可选同步：服务端基础已实现，未完成

- 新增 V5 encrypted sync 表。服务端只存 Base64 加密块、12-byte nonce、哈希、revision 和更新时间，不接收密钥。
- manifest、域开关、对象上传/下载和冲突解决接口；默认关闭且每个设备每个域还必须显式开启。
- 域白名单不包含 API Key；上传限制 2MB，并验证 SHA-256、AES-256-GCM 声明、nonce 与最低认证标签长度。
- 设备隔离存储；baseRevision 冲突拒绝写入；重复上传按设备和幂等键去重。
- `EncryptedSyncTest` 使用真实 Java AES-GCM 验证加密往返、明文不入库、设备隔离、域开关、幂等和冲突。

客户端 durable outbox、断网恢复、非敏感域试点、容量/损坏/重启验收和共享空间授权已实现；密钥跨设备导入/恢复短语与聊天/角色域仍未实现，因此不能宣称所有域的多设备同步完成。
