# M2 故事只读服务实施进度

## 状态

已完成服务端故事目录、校验发布、版本详情、关键词/标签筛选、cursor 分页和下载幂等统计。故事评论、在线投稿和社交互动继续关闭。

## 已实现接口

### 公共只读接口

```text
GET /api/stories?q=&tag=&cursor=&limit=20
GET /api/stories/{storyId}
GET /api/stories/{storyId}/versions/{version}
GET /api/stories/{storyId}/download?version=
```

列表响应同时提供现有 Flutter `StoryProvider` 需要的顶层结构和标准分页数据：

```json
{
  "stories": [],
  "nextCursor": null,
  "hasMore": false,
  "data": {"items": [], "nextCursor": null, "hasMore": false},
  "requestId": "req_..."
}
```

下载接口直接返回故事包 JSON，不包在 `data` 内，因而可直接被现有 `StoryPackage.fromJson` 解析。

### 管理员发布接口

```text
POST /api/admin/stories/publish
X-Admin-Token: <bootstrap token>
```

发布前校验 `schemaVersion`、故事 ID、版本、标题摘要、标签、章节顺序和全局唯一记忆点 ID。失败响应使用 `STORY_INVALID`，并在 `error.details` 中返回 JSON 路径。

## 下载统计和幂等

- 服务端发布故事的 `download_count` 只在下载成功后递增。
- 请求携带 `Idempotency-Key` 时，按设备/匿名来源、故事下载路由和键保存响应 24 小时；重复请求返回第一次响应，不重复计数。
- 没有幂等键的请求保持普通下载语义，每次成功下载都会计数。


## 自动化验证

`AuthAndStoryControllerTest` 已验证：

- 管理员发布合法故事；
- 错误故事返回字段级错误；
- 顶层 `stories` 和标签筛选可用；
