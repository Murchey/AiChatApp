# 01 从零启动与项目骨架

## 1. 固定技术基线

- Java 21 LTS。
- Spring Boot 3.x，使用 Spring Web、Validation、Actuator、JDBC、Flyway。
- SQLite JDBC 驱动；第一版使用 `JdbcTemplate`，不使用 JPA/Hibernate 的自动建表。
- Jackson 负责 JSON；所有外部输入先反序列化到 DTO，再映射到领域对象。
- Gradle Wrapper 固定版本，开发者使用 `./gradlew` 或 Windows 的 `gradlew.bat`，不要依赖全局 Gradle 版本。
- 测试使用 JUnit 5、Spring Boot Test、MockMvc；需要真实 SQL 时使用临时 SQLite 文件。

不要因为项目叫 AI 就默认加入 OpenAI SDK。HTTP 协议适配应放在自己的 adapter 中，供应商 SDK 只能作为可替换实现。

```text
│   └── backups/

│   ├── AiChatServerApplication.java
│   ├── config/                  # 配置、CORS、Jackson、限流
│   ├── common/                  # ApiResponse、错误码、分页、时钟
│   ├── auth/                    # 设备、令牌、管理员权限
│   ├── story/                   # 故事目录、版本、发布、下载

│       ├── web/

│   └── db/migration/V1__baseline.sql
└── src/test/

    └── resources/application-test.yml
```

每个业务模块固定分成 `web`、`service`、`repository`、`model`、`dto` 五层。Controller 不直接拼 SQL；Repository 不解析 HTTP；DTO 不直接作为数据库实体。

## 3. 最小 Gradle 依赖

```groovy
dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-web'
    implementation 'org.springframework.boot:spring-boot-starter-validation'
    implementation 'org.springframework.boot:spring-boot-starter-actuator'
    implementation 'org.springframework.boot:spring-boot-starter-jdbc'
    implementation 'org.flywaydb:flyway-core'
    runtimeOnly 'org.xerial:sqlite-jdbc'
    implementation 'com.fasterxml.jackson.datatype:jackson-datatype-jsr310'
    testImplementation 'org.springframework.boot:spring-boot-starter-test'
}
```

如果选择 WebFlux 或响应式流，必须整套采用，不能在同一请求链中混用阻塞 JDBC 和响应式 Controller。V1 推荐 Spring MVC + JDBC，流式 LLM 单独使用 `SseEmitter` 或 WebClient。

## 4. 配置文件

`application.yml` 只放非敏感默认值；敏感值通过环境变量覆盖：

```yaml
server:
  port: ${AICHAT_PORT:8080}
  forward-headers-strategy: framework
spring:
  datasource:
    url: jdbc:sqlite:${AICHAT_DATA_DIR:./data}/aichat.sqlite
  flyway:
    enabled: true
    locations: classpath:db/migration
  jackson:
    time-zone: UTC
management:
  endpoints:
    web:
      exposure:
        include: health,info
app:
  public-base-url: ${AICHAT_PUBLIC_BASE_URL:}
  invite-required: ${AICHAT_INVITE_REQUIRED:true}
  features:
    sync: ${AICHAT_FEATURE_SYNC:false}
    comments: ${AICHAT_FEATURE_COMMENTS:false}
    admin-publish: ${AICHAT_FEATURE_ADMIN_PUBLISH:true}
    llm-relay: ${AICHAT_FEATURE_LLM_RELAY:false}
  security:
    token-pepper: ${AICHAT_TOKEN_PEPPER:}
```

启动时如果令牌 pepper 为空应直接失败，而不是生成临时值；否则重启后所有设备令牌都会无法校验。

## 5. 从零启动顺序

1. 安装 Java 21，执行 `java -version` 确认版本。
2. 创建 Spring Boot 工程并加入上面的依赖。
3. 先实现 `/api/health`，确保端口、日志和打包可用。
4. 加入 Flyway `V1__baseline.sql`，启动空库并检查表已创建。
5. 实现统一错误处理和请求 ID，再实现设备令牌。
6. 实现故事只读接口，使用固定测试 JSON 通过集成测试。
7. 实现管理员发布流程，再打开评论等扩展模块。
8. 最后接入 Flutter Provider；不要一开始改动所有本地 Provider。

## 6. 常见错误

- 把 SQLite 数据库放在 JAR 内部：升级时会丢数据；必须使用外部 `data` 目录。
- 依赖工作目录：systemd 和 Windows 服务的当前目录不同，所有文件路径使用 `AICHAT_DATA_DIR` 或绝对路径。
- 用数据库自增 ID 作为客户端同步 ID：离线设备会冲突；对外 ID 使用 UUID/ULID。
- 让 Jackson 接受任意字段并静默丢弃：版本升级时难以发现拼写错误；输入 DTO 应开启未知字段告警或显式记录。
- Controller 直接返回 Entity：会泄露内部字段；始终经过 Response DTO。
- 用本地时间保存时间戳：服务器和客户端时区不同会造成排序错乱；数据库统一 UTC。
