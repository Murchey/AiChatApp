## 验证命令

在有网络且腾讯镜像可访问的环境中执行：

```powershell
cd server_project
.\gradlew.bat test
.\gradlew.bat bootJar
```

启动验证：

```powershell
$env:AICHAT_DATA_DIR = "$PWD\data"
.\gradlew.bat bootRun
Invoke-RestMethod http://127.0.0.1:8080/api/health
Invoke-RestMethod http://127.0.0.1:8080/api/version
```

预期：health 返回 `status=UP`；version 返回 `apiVersion=v1` 和 `features`；首次启动自动创建 `data/aichat.sqlite` 并执行 V1 迁移。

## 本次验证结果

- `server_project/gradlew.bat clean test bootJar`：通过，M0 系统测试与 M1/M2 集成测试全部通过。
- `server_project/gradlew.bat bootJar`：通过，生成 `server_project/build/libs/aichat-backend.jar`。
- 使用临时端口 `18080` 启动打包 JAR：通过，Flyway 执行 V1 迁移。
- `GET /api/health`：返回 `status=UP`。
- `GET /api/version`：返回 `apiVersion=v1`、`stories=true`、`comments=false`。
- Windows 测试曾遇到临时 SQLite 文件被 Spring 连接池锁定的问题，已改为唯一内存 SQLite URI，避免测试残留文件。
- 自定义 `AICHAT_DATA_DIR` 不存在时 SQLite 不会自动创建父目录，`scripts/run.ps1` 和 `scripts/run.sh` 已加入自动创建目录逻辑。

## 环境限制与处理

当前工作机有 Java 21，但没有全局 `gradle` 或 `mvn`。因此不安装全局工具，使用项目内 Wrapper；第一次构建需要从腾讯镜像下载 Gradle 和 Maven 依赖。如果镜像不可达，记录失败 URL 和错误后再处理，不修改 Git 历史或绕过镜像配置。
