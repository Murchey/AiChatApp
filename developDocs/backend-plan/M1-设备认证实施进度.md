# M1 设备认证实施进度

## 状态

已完成实现与自动化验证。M1 只保存令牌哈希，不保存邀请码、access token 或 refresh token 明文。

## 已实现

- [x] 邀请码生成：`POST /api/admin/invites`。
- [x] 邀请码限次数和过期时间，兑换使用条件更新避免超用。
- [x] `POST /api/invite/exchange` 创建设备并返回短期 access token、refresh token。
- [x] SHA-256 加 token pepper 哈希，数据库只保存 access/refresh 哈希。
- [x] `POST /api/auth/refresh` 一次性 refresh token 轮换。
- [x] 检测已使用/过期 refresh token 的重放，并撤销该设备其余 refresh token。
- [x] `POST /api/auth/revoke` 自助撤销当前设备。
- [x] `POST /api/admin/devices/{deviceId}/revoke` 管理员撤销设备。
- [x] Bearer 令牌过滤器、设备状态和过期时间校验。
- [x] bootstrap 管理员令牌（`AICHAT_BOOTSTRAP_ADMIN_TOKEN`）和设备 ADMIN 角色。
- [x] 邀请兑换、刷新和管理员操作的内存限流。
- [x] `admin_audit_log` 写入邀请码创建、设备撤销和故事发布审计记录。
- [x] 统一 `ApiException` 错误码和 `requestId`。

## 配置

```text
AICHAT_TOKEN_PEPPER             生产环境至少 32 字符
AICHAT_REQUIRE_TOKEN_PEPPER     是否在启动时强制检查 pepper
AICHAT_BOOTSTRAP_ADMIN_TOKEN    首次生成邀请码/发布故事的管理令牌
AICHAT_ACCESS_TOKEN_MINUTES     access token 有效期，默认 15 分钟
AICHAT_REFRESH_TOKEN_DAYS       refresh token 有效期，默认 30 天
```

bootstrap 管理令牌只用于初始化管理员操作，应通过环境变量注入，不写入仓库配置和日志。后续可以使用设备 ADMIN 令牌替代它。
