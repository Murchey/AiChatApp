# M5 设置同步试点实施进度

更新：2026-10-09。本文件补充 M4–M7 总进度，当前不将试点等同于完整多设备同步。

## 已实现

- Flutter `SyncCrypto`：AES-256-GCM、随机32字节密钥/12字节nonce、SHA-256密文校验；错误密钥或认证标签拒绝解密。
- `SyncOutboxStore`：SQLite本地密文与待发送记录事务写入，按服务器地址、设备ID、域隔离；多个未发送编辑可以合并。
- 已尝试上传单独冻结在 `sync_inflight`，后续编辑不能覆盖其内容或幂等键。断网、响应确认丢失或进程重启后先重放原请求，确认后再基于新revision发送后续编辑。
- 过期/重复ACK不会回退本地remote revision。409冻结该域；显式保留本机时读取远端revision再重排上传；选择恢复远端时清除该域旧待发送记录。
- `SyncService`：共享设备认证、feature gate、401刷新、取消、服务器切换隔离，核验ACK的revision与哈希；一次操作最多处理16批，防止持续编辑导致无限循环。
- `SyncProvider`与“设置同步（试点）”二级页：位于故事线设置的自建服务器配置区域。默认关闭，明确开关、上传、恢复和保留本机操作；安全存储失败不回退到明文偏好。
- 首个域只包含 `schemaVersion`、`themeMode`、`homeNavigationStyle`。无关设置通知不产生同步写入；所有气泡数据、角色、聊天、API Key、文件路径不读不上传。
- 仅用户主动执行上传时发送对象；本地设置监听只写密文outbox。构造Provider不发送请求或打开数据库。
- V8 增加共享空间、OWNER/MEMBER 成员表、一次性加入码和空间级加密对象/幂等表。旧的设备私有路径保持兼容；带 `X-Sync-Space` 时服务端按空间成员授权和revision隔离。
- App 提供密码保护的同步密钥导出/导入：PBKDF2 + AES-GCM 包裹客户端密钥，复制的是加密包，不是原始密钥。共享空间加入后导入同一密钥才能解密另一设备上的对象。

## 尚未完成/交付边界

- 共享空间服务端授权和空间级对象已实现；仍未实现跨设备密钥传递/恢复短语，因此“多设备同步”只有在用户通过安全方式把同一客户端密钥带到第二设备后才可解密。App当前提供空间选择和加入入口，但不上传密钥。
- 当前没有自动恢复短语或服务端托管密钥；用户必须主动导出/导入并保管密码。清除系统安全存储且没有加密导出包时旧密文不可恢复。
