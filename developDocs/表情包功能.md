## 二、数据模型设计

### 2.1 `MessageType` 扩展（lib/models/message.dart）

```dart
enum MessageType { text, image, file, sticker, system }
```

**决策理由**：
- 新增 `sticker` 类型，与 `image` 完全隔离
- sticker 的 content 存储方式与 image 一致（文件路径或包内相对路径）
- sticker 不入对话上下文（类似 image/file 被 `_buildHistory` 过滤），但可注入系统提示词让角色感知用户发了表情包

## 三、状态管理与持久化

### 3.1 `StickerProvider`（lib/providers/sticker_provider.dart）

新建 ChangeNotifier Provider，管理表情包生态：

```dart
class StickerProvider extends ChangeNotifier {
  static const _packsKey = 'sticker_packs_v1';       // 创意工坊导入的表情包合集
  static const _userStickersKey = 'user_stickers_v1'; // 用户自定义表情包列表
  
  List<StickerPack> _packs = [];
  List<UserSticker> _userStickers = [];
  
  // === Getter ===
  List<StickerPack> get packs => List.unmodifiable(_packs);
  List<UserSticker> get userStickers => List.unmodifiable(_userStickers);
  
  /// 获取某包的所有图片路径
  List<String> imagePathsFor(String packId) => 
      _packs.firstWhere((p) => p.id == packId).imagePaths;
  
  // === API ===
  Future<void> importStickerPack(StickerPack pack);
  Future<void> removeStickerPack(String packId);
  Future<void> addUserSticker({required String imagePath, required String label});
  Future<void> removeUserSticker(String stickerId);
  Future<List<UserSticker>> importFromZip(Archive archive);  // 从导入zip提取
  void incrementUseCount(String stickerId);  // 使用后更新计数
  
  // 持久化 + init
}
```

**持久化策略**：
- `SharedPreferences` 存储元数据（pack 列表 + userStickers 列表，不含图片二进制）
- 图片文件存储在应用文档目录下的 `/stickers/` 子目录
- 与 ChatProvider 的防抖落盘模式不同，StickerProvider 每次变更都即时落盘（表情包操作频率低）

### 3.2 `ChatProvider` 扩展

在 `sendImageMessage` 旁新增：

```dart
/// 发送表情包消息
Future<void> sendStickerMessage({
  required String conversationId,
  required String stickerPath,   // 图片文件路径
  required String? label,        // 表情包备注（可为空）
  required String characterName,
}) async {
  final userMessage = Message(
    id: const Uuid().v4(),
    conversationId: conversationId,
    content: stickerPath,
    type: MessageType.sticker,
    sender: MessageSender.user,
    stickerLabel: label,
  );
  
  _messagesMap[conversationId] ??= [];
  _messagesMap[conversationId]!.add(userMessage);
  _updateConversationLastMessage(conversationId, '[表情包]' + (label?.trim() ?? ''));
  notifyListeners();
  await _persist();
  
  // 触发角色对表情的回复
  await _handleStickerReply(conversationId, stickerPath, label, characterName);
}
```

**角色回复表情包逻辑 `_handleStickerReply`**：

```dart
/// 用户发送表情包后，根据角色是否支持视觉模型来决定回复方式
Future<void> _handleStickerReply(...) async {
  final model = await _resolveModel(...);
  
  if (model.isVisionSupported) {
    // 视觉模型：将图片发送给模型，让它「看到」并回复
    return await generateProactiveMessages(
      imagePath: stickerPath,  // 走视觉格式
    );
  } else {
    // 非视觉模型：只把 label 发给模型（要求 label 不为空）
    if (label == null || label.trim().isEmpty) {
      return; // 不允许发送无备注表情包给非视觉模型
    }
    // 将 label 作为文本内容拼入历史上下文
    final historyWithStickerContext = _buildHistoryWithStickerContext(
      conversationId,
      label: label,
    );
    return await generateProactiveMessages(
      historyMessages: historyWithStickerContext,
    );
  }
}
```

  required GroupMemberReply member,
  required String replyContent,
  required String conversationId,

  // 10% 概率附带表情包
  const stickerChance = 0.1;
  if (Random().nextDouble() >= stickerChance) return;
  
  // 从全局表情池中随机选取
  final provider = ServicesLocator.stickerProvider;

    conversationId: conversationId,
    stickerPath: randomImage,
    senderCharacterId: member.characterId,
    senderName: member.name,
  );
}

**布局参数**：
- **总高度**：`min(320dp, MediaQuery.of(context).size.height * 0.4)` — 默认 320dp，不超过屏幕 40%
- **内部 Padding**：上下各 8dp，左右各 4dp
- **GridView**：`crossAxisCount: 4`（每行 4 个），`mainAxisSpacing: 8`，`crossAxisSpacing: 8`
- **单个格子**：正方形（宽高相等，按可用空间均分）
- **左上角**：固定为「➕ 添加」按钮（特殊样式，浅灰色背景 + 大号字体图标）
- **剩余空间**：`ScrollView` + `GridView`，支持上下滚动浏览更多表情包
- **底部操作栏**：固定不随滚动，高度 64dp，包含「取消」「编辑」「发送」三个按钮

**交互逻辑**：
1. 点击表情按钮 → 面板从底部滑出（动画 200ms, Curves.easeOut）
2. 面板弹出时自动收起已打开的加号网格菜单
3. 点击「取消」→ 面板收起（回到输入状态）
4. 点击「➕ 添加」→ 跳转到相册/拍照选择器，选完图片后自动添加到收藏夹
5. 点击「编辑」→ 进入编辑模式（见 5.4）
6. 选中某个表情包后「发送」按钮变为高亮状态
7. 点击「发送」→ 将选中表情包发送给角色，关闭面板，清空选择状态

### 7.3 表情包导入流程

用户在创意工坊勾选某个 V1.3.0 表情包 zip → 点击下载 → 解压并存储：

```dart
/// 从下载的 zip 中提取表情包数据
Future<StickerPack> parseStickerPackZip(Uint8List zipBytes, String sourceRepo) async {
  final archive = ZipDecoder().decodeBytes(zipBytes);
  final images = <String>[];
  final labels = <int, String>{};
  
  for (final file in archive.files) {
    if (_isImageFile(file.name)) {
      // 保存图片到 /stickers/packs/{uuid}/
      final dir = Directory('${docsDir.path}/stickers/packs/$uuid');
      await dir.create(recursive: true);
      final path = '${dir.path}/${file.name.split('/').last}';
      await File(path).writeAsBytes(file.content as List<int>);
      images.add(path);
      
      // 如果有同名 .txt 文件，读取 label
      final labelFile = archive.files.where((f) => f.name.replaceAll('.png', '.txt')).firstOrNull;
      if (labelFile != null) {
        labels[images.length - 1] = utf8.decode(labelFile.content as List<int>);
      }
    }
  }
  
  return StickerPack(
    id: const Uuid().v4(),
    name: ...,
    author: ...,
    coverImage: images.isNotEmpty ? images.first : '',
    imagePaths: images,
    importedAt: DateTime.now(),
    labels: labels,
  );
}
```

### 8.2 导入（ChatRecordsService.importZip 扩展）

导入时需要**用哈希特征值比较**来确定是否需要重新下载/导入表情包：

```dart
// importZip 中解析 sticker 消息
if (type == MessageType.sticker) {
  final entry = fileMap[content];  // stickers/xxx.png
  if (entry != null) {
    // 计算导入包的这张图片的 SHA256
    final imageBytes = entry.content as List<int>;
    final hash = sha256.convert(imageBytes).toString();
    
    // 查询本机已有表情包是否有相同哈希
    final stickerProvider = ServicesLocator.stickerProvider;
    final existing = stickerProvider.userStickers.where(
      (s) => s.id.startsWith(hash.substring(0, 16))
    ).toList();
    
    if (existing.isNotEmpty) {
      // 本机已有此表情包，直接复用路径
      content = existing.first.imagePath;
      // 不重复保存到磁盘
    } else {
      // 本机没有，保存到 stickers/custom/ 目录
      final safeName = '$hash.${_extensionOf(content)}';
      final targetFile = File('${importDir.path}/$safeName');
      await targetFile.writeAsBytes(imageBytes);
      content = targetFile.path;
      
      // 同时将此表情包加入用户收藏（可选：标记来源）
      await stickerProvider.addUserSticker(
        imagePath: content,
        label: map['sticker_label'] as String?,
      );
    }
  }
}
```

**去重策略流程图**：

```
导入表情包图片
    ↓
计算 SHA256 哈希
    ↓
查询 StickerProvider.userStickers 是否已有同哈希条目
    ├─ 有 → 复用已有文件路径（不重复保存）
    └─ 无 → 保存到 stickers/custom/ 并加入用户收藏
```
