# AiChat 后端：5 分钟快速开始

这份说明适合第一次运行 Java 服务的开发者。服务使用 Java 21、Spring Boot 和 SQLite，数据保存在本地文件中。

## 1. 安装 Java 与 Node.js

安装 Java 21，并在终端确认：

```text
java -version
```

使用 Java 21。项目自带 Gradle，不需要单独安装 Gradle。构建管理面板还需要 Node.js 20.19+ 或 22.12+ 和 npm。

## 2. 启动服务

进入本文件所在项目的 `server_project` 目录。

Windows PowerShell：

```powershell
.\scripts\setup-local.ps1
.\scripts\start.ps1
```

Linux/macOS：

```bash
chmod +x scripts/start.sh
./scripts/start.sh
```

Windows 初始化会生成 `config/local.env`，其中的 `AICHAT_BOOTSTRAP_ADMIN_TOKEN` 用于登录管理面板；已有文件不会被覆盖。启动默认重新构建管理面板和 JAR。首次下载依赖可能需要几分钟，看到 `Started AiChatServerApplication` 就表示启动成功。Linux 使用环境变量设置随机管理令牌与 token pepper，参考部署指南。

## 3. 检查服务

打开浏览器访问：

```text
http://127.0.0.1:8080/api/health
```

如果返回包含 `"status":"UP"`，服务正常。根地址 `/` 是管理面板（构建过管理面板时可用）。

## 4. 让 App 连接

在 App 的“发现 → 故事线社区 → 设置”中选择“自建服务器”，填写：

```text
地址：你的服务器域名或 IP
端口：8080（如果使用 HTTPS 反向代理，通常是 443）
协议：HTTP 或 HTTPS
```

电脑本机测试可填写 `http://127.0.0.1:8080`；手机测试要填写电脑局域网地址，例如 `http://192.168.1.20:8080`。地址已包含端口时，单独的端口栏可留空。不要在手机上填写 localhost / 127.0.0.1，也不要把 `/api` 追加到服务器地址末尾。确认监听地址为 `0.0.0.0`，并允许防火墙访问端口。

## 5. 一键打包部署

Windows：

```powershell
.\scripts\deploy.ps1
```

Linux/macOS：

```bash
chmod +x scripts/deploy.sh
./scripts/deploy.sh
```

脚本会运行测试、生成 `build/libs/aichat-backend.jar`，并复制到本机部署目录。默认目录为：

- Windows：`%LOCALAPPDATA%\AiChat\server`
- Linux/macOS：`$HOME/.aichat/server`

部署脚本不会自动修改云服务器、防火墙或域名。云服务器请按 [部署指南](部署指南.md) 配置 systemd 和 HTTPS。

## 6. 常见问题

**端口被占用**：换一个端口启动，例如 Windows 使用 `-Port 18080`，Linux 使用 `PORT=18080 ./scripts/start.sh`。

**数据在哪里**：默认在 `server_project/data`。部署脚本会把数据放在部署目录旁的 `data` 文件夹。不要让两个服务同时使用同一个数据目录。

**为什么手机访问不了**：确认手机和电脑在同一网络、系统防火墙已允许端口，并且 App 填写的是电脑局域网 IP，而不是 `127.0.0.1`。

**如何停止**：启动窗口按 `Ctrl+C`。systemd 部署使用 `sudo systemctl stop aichat`。

## 7. 管理面板

管理面板源码在 `admin-panel/`。源码修改后，在 `server_project` 执行：

```text
.\scripts\build.ps1
```

Linux 使用 `sh scripts/build.sh`。构建脚本先构建面板，再测试与打包后端；任何步骤失败都会停止。服务启动后访问根地址即可打开面板，登录后使用故事线、角色卡、用户邀请和评论审核页面。管理员令牌不要提交到 Git，也不要发到聊天或截图中。
