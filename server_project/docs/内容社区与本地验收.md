# 内容社区与本地验收

服务器管理角色包、故事版本和读者评论。内容由管理员发布；目录、下载和已审核评论公开；发表评论、回复和举报需要登录服务器账户，旧邀请码设备令牌仍然兼容。新评论仍为 PENDING，管理员通过后公开；角色与故事共用审核队列。

## APP 服务器账户

在「故事线设置 → 自建服务器」填写服务器根地址、账户名、密码，选择「注册并登录」或「登录服务器账号」。开放注册无需邀请码；账户名为 3–32 位字母、数字或下划线，不区分大小写；密码至少 8 个字符，最多 72 个 UTF-8 字节。密码使用 BCrypt 哈希，APP 请求完成后清空密码框，不保存密码。令牌复用安全存储，重启可恢复登录；网络或服务端临时故障保留会话，确认令牌失效才清除。

「服务器连接成功」与「账号已登录」分别显示。退出只撤销当前服务器设备会话并清除本机令牌，保留账户名、本地聊天、角色和设置；切换服务器清除原会话信息。服务器账户独立于本地昵称。没有忘记密码、启动登录页或个人页入口。邀请码、设备 ID 和手动令牌在「高级认证」中，供旧服务器与管理员设备使用。

`POST /api/auth/register` 和 `POST /api/auth/login` 接受 `{"username":"beta_user","password":"your-password"}`，返回 `data.userId / username / deviceId / accessToken / refreshToken / accessExpiresAt / refreshExpiresAt`。注册即登录；每次登录由服务端生成新的 USER 设备会话，客户端不能指定角色或设备 ID。`GET /api/auth/me` 需要 Bearer 令牌；刷新与退出沿用 `/api/auth/refresh` 和 `/api/auth/revoke`。注册每 IP 每分钟 5 次，登录 10 次；账户重名返回 409，错误凭据返回 401「账户名或密码错误」。

`/api/version` 的 `features.accountAuth` 由 `AICHAT_FEATURE_ACCOUNT_AUTH` 控制，默认开启，与旧邀请码开关独立。旧服务器未声明此能力时 APP 不发送账号密码，仍可使用高级认证。

## 本地启动

在 `server_project` 执行：

```powershell
.\scripts\setup-local.ps1
.\scripts\start.ps1
```

在 `config/local.env` 查看 `AICHAT_BOOTSTRAP_ADMIN_TOKEN`，访问 `http://127.0.0.1:8080` 登录。初始化只创建缺失的配置，不轮换现有密钥。`config/local.env` 不进 Git。本地初始化开启评论；直接运行 JAR 或生产部署时仍由 `AICHAT_FEATURE_COMMENTS` 显式开启。

`start.ps1` 默认构建最新管理面板与 JAR；确认已构建时可使用 `-SkipBuild`。`deploy.ps1` / `deploy.sh` 也先构建面板，测试失败不部署，不覆盖已有 `aichat.env`。安装后的 `launch.ps1` / `launch.sh` 会加载该环境文件，避免配置写入文件却未用于启动。

手机联调时填写 `http://电脑局域网IP:8080`，同网且放行防火墙；手机的 localhost 指向手机自身。填写服务器根地址，不能追加 `/api`。原生 Android 请求不受浏览器 CORS 限制，不能把 CORS 当作所有连接失败的修复方法。

`AICHAT_BIND_ADDRESS` 默认 `0.0.0.0` 用于本地局域网访问；生产 systemd 模板固定为 `127.0.0.1`，由 HTTPS 代理提供访问。`AICHAT_PUBLIC_BASE_URL` 可配置管理台显示的外部地址。Vite 开发服务器代理 `/api` 到本机 8080。

## 管理操作

- 登录请求 `/api/admin/session` 验证管理令牌，失败保持登录页。
- 故事线：新建或导入 JSON，编辑章节与记忆点，保存草稿、校验、发布。修改已发布草稿时默认进入下一版本；保留 revision 和 baseVersion 乐观锁，冲突不会覆盖线上内容。归档后停止下载。
- 角色卡：上传沿用 App 格式的 ZIP，包内需有 `角色目录/Profile.json`。首版本为 1，更新为当前版本加一；版本不可变。支持标题、作者、简介和历史版本下载。当前限制压缩包 4MB、解压总量 32MB、2000 项，拒绝危险路径和无效 JSON。
- 用户邀请：选择普通用户或管理员、次数和有效小时，生成并复制邀请码。
- 评论审核：分页查看待审核、已通过、隐藏和删除的评论，可通过、隐藏、删除。操作中按钮禁用，错误展示请求编号；功能关闭时说明如何开启。

管理台使用独立 CSS 和原生可访问表单，不依赖未配置的 HeroUI / Tailwind 样式。导航切换保留编辑内容；离开页面时提示未保存内容。服务健康、版本、管理员配置分别加载，单项失败会显示错误。

## 新接口

管理接口均需 `X-Admin-Token` 或 ADMIN 设备 Bearer：

```text
GET  /api/admin/session
GET  /api/admin/connection
GET  /api/characters?q=&cursor=&limit=20
GET  /api/characters/{id}
GET  /api/characters/{id}/download?version=1
POST /api/admin/characters?characterId=...&title=...&author=...&summary=...&version=1
     Content-Type: application/zip，body 为 ZIP 原始字节
GET  /api/characters/{id}/comments?cursor=&limit=20
POST /api/characters/{id}/comments
     Authorization: Bearer ...，Idempotency-Key: ...，body: {"body":"评论正文"}
```

公开角色接口不需管理员权限。目录返回 `data.items / hasMore / nextCursor`；详情返回 `data`；下载返回 ZIP。角色评论返回 `characterId`，旧故事评论继续返回 `storyId`。既有评论结构中的 `storyVersion` 在角色评论中表示所评论的角色版本。回复、删除、举报和审核沿用 `/api/comments/...` 与 `/api/admin/comments/...`。不返回作者设备 ID。

`/api/version` 增加 `features.characters`，由 `AICHAT_FEATURE_CHARACTERS` 控制，默认开启。旧故事 API 与顶层 `stories` 兼容字段保留。

## 迁移与测试

V9 新增角色目录与 ZIP 版本存储，并迁移评论表以支持角色或故事目标。保留旧评论 ID、正文、状态、公开资格、回复与举报；已存在的迁移文件没有修改。升级前停止服务并备份数据库和环境配置，回退时恢复对应旧库。角色包保存在 SQLite 中，一并备份。

V10 新增账户表与可空的设备账户关联，旧设备、权限、令牌、故事、角色、评论及举报保留，不自动合并旧设备或其私有同步空间到新账户。

```powershell
.\scripts\build.ps1
```

后端测试包括认证与角色版本下载、ZIP 格式与大小、匿名拒绝、评论审核、角色回复、举报、旧数据库升级与外键完整性。

构建后执行 `node scripts/account-smoke.cjs`，脚本启动随机本地端口与临时数据库，通过实际 Flutter 客户端走通注册、重启会话恢复、退出后令牌失效、重新登录与刷新。需要 PATH 中有 Java 和 Flutter。APP 配置页交互与网络故障会话保留另有单元及组件测试。

管理台的浏览器流程可用 `node scripts/admin-smoke.cjs` 验证，需要可用的 Playwright 与 Chromium（也可通过 `AICHAT_PLAYWRIGHT_PATH` / `AICHAT_BROWSER_PATH` 指定安装位置）。脚本启动随机端口与临时数据库，验证登录、故事草稿/发布/更新、角色上传/下载、邀请码兑换/刷新、评论审核及移动端溢出；完成后停止测试服务。截图在 `build/qa/`。

本次验收覆盖本地服务端、管理台与 APP 账号流程，不代表云端部署或 Android 真机连接成功。App 的云角色卡目录与评论 UI 尚需后续接入；已有故事线服务可按原客户端协议使用。
